Соотношение сторон: Лучше всего сделать все фото квадратными (1:1). Это позволит карусели выглядеть аккуратно и симметрично.

Каждое изображение не должно превышать 100–150 Кб. В идеале — меньше 80 Кб.
Рекомендуемый: WebP. Это современный формат, который обеспечивает отличное качество при гораздо меньшем размере файла (на 30-50% меньше, чем JPEG). Все современные браузеры его поддерживают.



Предположим, вы подготовили 10 отличных квадратных фотографий в формате WebP и назвали их work1.webp, work2.webp, ..., work10.webp.

В корневой папке сайта (там, где лежит файл index.html) создайте новую папку и назовите ее, например, img.Загрузите все ваши подготовленные фотографии (work1.webp и т.д.) в эту папку img.

Важно: Для каждого изображения заполняйте атрибут alt="" осмысленным описанием — это критически важно для SEO-оптимизации по картинкам.

В коде есть JavaScript, который автоматически заполняет галерею серыми квадратами. После того как вы добавили реальные фото в HTML, этот скрипт нужно удалить или закомментировать.

<script>
    document.addEventListener('DOMContentLoaded', () => {
        const track = document.getElementById('carouselTrack');
        const totalImages = 20; // Кількість заглушок у каруселі

        // Динамічне створення заглушок 250x250
        for (let i = 1; i <= totalImages; i++) {
            const slide = document.createElement('div');
            slide.className = 'carousel-slide';
            slide.innerHTML = `<img src="https://via.placeholder.com/250x250/181b22/f39c12?text=Робота+${i}" alt="Приклад гравірування ${i}">`;
            track.appendChild(slide);
        }

        // ... остальная логика карусели ...
    });
</script>
