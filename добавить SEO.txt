Чтобы превратить одностраничный сайт-визитку в эффективный инструмент для привлечения клиентов из Google (особенно в локальной выдаче Запорожья), базовых тегов `title` и `description` недостаточно.

Ниже подробно разобрано, **что именно**, **зачем** и **в какие блоки HTML-кода** нужно добавить.

---

## 1. Микроразметка Schema.org (LocalBusiness)

Google должен четко понимать, что сайт принадлежит физическому офлайн-бизнесу с конкретным адресом, графиком работы и диапазоном цен. Это повышает шансы попадания в блок локальной выдачи (Google Maps / Local Pack).

### Куда вставлять:

В секцию `<head>...</head>` перед закрывающим тегом `</head>`.

### Код для вставки:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Майстерня лазерного гравірування «Акцент»",
  "image": "https://akcent.zp.ua/logo.jpg", 
  "@id": "https://akcent.zp.ua/#organization",
  "url": "https://akcent.zp.ua/",
  "telephone": "+380676123993",
  "priceRange": "від 200 UAH",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "пр. Соборний, 147, ТЦ Україна, 1 поверх",
    "addressLocality": "Запоріжжя",
    "postalCode": "69000",
    "addressCountry": "UA"
  },
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": 47.842554,
    "longitude": 35.131036
  },
  "openingHoursSpecification": {
    "@type": "OpeningHoursSpecification",
    "dayOfWeek": [
      "Monday",
      "Tuesday",
      "Wednesday",
      "Thursday",
      "Friday",
      "Saturday",
      "Sunday"
    ],
    "opens": "10:00",
    "closes": "19:00"
  },
  "sameAs": [
    "https://www.instagram.com/akcent.zp.ua"
  ]
}
</script>

```

*(Не забудьте скорректировать часы работы `opens`/`closes`, если они отличаются).*

## 2. Расширение семантического ядра и H2/H3 заголовков

Пользователи ищут лазерную гравировку не только общими фразами, но и по конкретным предметам. Если этих слов нет в заголовках или тексте, страница не будет по ним ранжироваться.

### Что добавить в семантику:

* *Гравировка клавиатуры / ноутбука / кириллица* (очень частотный запрос в Запорожье).
* *Гравировка жетонов, ручек, ножей, термосов, свадебных бокалов, обручальных колец*.
* *Срочная гравировка (за 15–30 минут)*.

### Куда и как вносить изменения:

1. **В секцию «Наши услуги» (`<section>` с классом `services-grid`)**
Стоит расширить карточки услуг или добавить текстовый блок-перечисление популярных предметов, например:
```html
<!-- Новый блок или текстовое дополнение внутри секции услуг -->
<div style="margin-top: 30px; text-align: center; color: var(--text-muted);">
    <p><strong>Популярні напрямки:</strong> гравіювання клавіатур ноутбуків (укр/рус раскладка), військових жетонів, пам'ятних написів на ножах, годинниках, обручках, термосах та пауербанках.</p>
</div>

```


2. **В атрибуты `alt` галереи работ**
Google Картинки генерируют хороший целевой трафик. Заглушки или реальные фото должны иметь осмысленные `alt`-описания.
**Куда:** В JS-скрипте, где создаются слайды галереи.
```javascript
// Вместо абстрактного "Приклад гравірування 1"
const altTexts = [
    "Гравірування клавіатури ноутбука в Запоріжжі",
    "Лазерне гравірування на металевому армійському жетоні",
    "Персоналізація шкіряного гаманця написи та логотипи",
    "Гравіювання на мисливському ножі ТЦ Україна",
    "Пам'ятне гравірування на термосі та чашці"
];

// В цикле создания карточек задавать конкретный altText[i]

```

## 3. SEO-оптимизация часто задаваемых вопросов (FAQ + Микроразметка)

Поисковые системы любят структурированный контент формата «Вопрос-Ответ». Блок FAQ закрывает возражения клиентов и позволяет занять больше места в поисковой выдаче (расширенный сниппет).

### Куда вставлять:

Добавьте отдельную секцию `<section>` перед блоком контактов (футером).

### Код секции FAQ:

```html
<section>
    <div class="container">
        <h2 class="section-title">Часті запитання (FAQ)</h2>
        <div class="price-box" style="max-width: 800px;">
            <div class="info-block">
                <h4>Скільки часу займає гравірування?</h4>
                <p>Більшість замовлень (наприклад, гравіювання клавіатури, жетона чи ручки) виконуються протягом 15–30 хвилин безпосередньо у нашій майстерні в ТЦ "Україна".</p>
            </div>
            <div class="info-block">
                <h4>Чи можна вигравіювати клавіатуру ноутбука?</h4>
                <p>Так, ми виконуємо нанесення українських та українсько-англійських літер на клавіатури будь-яких моделей ноутбуків (MacBook, ASUS, Lenovo, Dell тощо).</p>
            </div>
            <div class="info-block">
                <h4>Як підготувати зображення, якщо немає векторного файлу?</h4>
                <p>Ви можете принести звичайне фото або картинку. Наші дизайнери допоможуть перевести її у векторний формат прямо на місці.</p>
            </div>
        </div>
    </div>
</section>

```

### Микроразметка FAQPage (для `<head>`):

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "Скільки часу займає гравірування?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "Більшість замовлень (наприклад, гравіювання клавіатури, жетона чи ручки) виконуються протягом 15–30 хвилин безпосередньо у нашій майстерні в ТЦ Україна."
    }
  }, {
    "@type": "Question",
    "name": "Чи можна вигравіювати клавіатуру ноутбука?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "Так, ми виконуємо нанесення українських літер на клавіатури будь-яких моделей ноутбуків (MacBook, ASUS, Lenovo, Dell тощо)."
    }
  }]
}
</script>

```

## 4. Технические SEO-улучшения

Для высотной индексации посадочной страницы требуются стандартные служебные файлы и теги.

1. **Favicon (иконка вкладки)**
Без иконки сайт теряет кликабельность (CTR) в мобильной выдаче Google.
**Куда:** В `<head>`
```html
<link rel="icon" href="/favicon.ico" type="image/x-icon">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">

```


2. **Канонический URL (Canonical Tag)**
Исключает проблемы с дублями страниц (например, с `www` и без `www`, или с `http` и `https`).
**Куда:** В `<head>`
```html
<link rel="canonical" href="https://akcent.zp.ua/">

```


3. **Файл `robots.txt**`
Создайте файл `robots.txt` в корневой папке сайта на хостинге:
```text
User-agent: *
Allow: /
Sitemap: https://akcent.zp.ua/sitemap.xml

```


4. **Файл `sitemap.xml**`
Даже для одностраничного сайта рекомендуется положить в корень файл `sitemap.xml`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://akcent.zp.ua/</loc>
    <lastmod>2026-08-14</lastmod>
    <changefreq>monthly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>

```

## 5. Внешняя локальная оптимизация (Вне сайта)

Для локального поиска 50% успеха определяет не сам сайт, а связка с **Google Business Profile (Google Карты)**.

1. **Google Business Profile:**
* Зарегистрируйте (или подтвердите права на) точку на Google Картах по адресу: *м. Запоріжжя, пр. Соборний, 147, ТЦ "Україна"*.
* В поле «Веб-сайт» профиля Google Business укажите ссылку `[https://akcent.zp.ua/](https://akcent.zp.ua/)`.
* Категории бизнеса в Google Profile: *Сервіс лазерного гравіювання*, *Майстерня*, *Магазин подарунків*.
* Название профиля: **Лазерне гравірування «Акцент» | ТЦ Україна**.


2. **Работа с отзывами:**
* Мотивируйте клиентов оставлять отзывы на Google Картах (в отзывах клиенты часто используют ключевые слова: *"быстро выгравировали клавиатуру"*, *"отличная гравировка на ноже"* — это напрямую поднимает сайт и карту в выдаче Запорожья).
